# 모델 검수

검수하려는 형상이나 관계가 의도대로 성립하는지 확인한다. 결과물을 만들거나 뷰를 열었다는 사실은 검수 통과의 근거가 아니다.

1. 현재 모델에서 검수 범위를 잡고, 무엇이 맞아야 하는지 확인한다. 수정한 객체뿐 아니라 수정으로 영향을 받은 주변 관계도 검수 범위에 포함한다.
2. 그 관계를 직접 확인할 수 있는 뷰나 조회를 골라 본다. 화면에서 판단할 수 없는 간격·겹침·접합은 필요한 형상과 치수를 더 확인한다. 보이지 않는 부분은 이상 없음이 아니라 미확인으로 남긴다.
3. 문제가 있으면 어디에서 무엇이 맞지 않는지, 어떤 근거로 판단했는지 남긴다. 수정했다면 문제가 생긴 조건에서 다시 확인한다. 검수 결과와 아직 확인하지 못한 부분을 구분해 전달한다.
