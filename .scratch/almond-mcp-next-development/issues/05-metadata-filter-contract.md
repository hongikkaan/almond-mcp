# 05: 객체 메타데이터 필터 호출 계약

**What to build:** 사용자가 객체 메타데이터를 조건으로 조회하고, 잘못된 입력을 받으면 어떤 형식으로 고쳐야 하는지 알 수 있다.

**Blocked by:** None (can start immediately)

**Status:** integrated

- [ ] 조건 배열에 대한 정상 호출 예시를 제공하고, 실제 단일 조건 배열과 복수 조건 배열을 검증한다.
- [ ] 배열 대신 단일 객체를 전달하면 기대 입력 형식을 구체적으로 알린다. 기존 source, key, any_of 의미를 보존한다.
- [x] [요소별 저장 대상·조회·필터·선택 범위](../../../src/mcp/rhino/OBSERVATION-SPEC.md#rhino-요소별-메타데이터와-조회-범위)를 기록했다.
- [ ] 실제 `.3dm` 저장·재열기 후 값과 GUID, 그룹 소속과 선택을 확인한다.

**검증 상태**

`fb4cb855`에 통합. 공개 호출 관련 작업 브랜치 검사 57개, 통합 객체 조회 32개 통과. 실모델 필터 결과 및 3DM 재열기 검수 대기.
