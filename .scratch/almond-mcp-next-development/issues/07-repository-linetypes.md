# 07: 저장소 선종 정의와 문서의 기존 선종 재사용

**What to build:** 도면 스타일은 저장소의 선종 manifest를 읽고, Rhino 문서에 이미 정의된 같은 이름의 선종은 그대로 쓴다.

**Blocked by:** None (can start immediately)

**Status:** integrated

- [ ] 실행 시 저장소 manifest에서 레이어 정의와 별도로 선종 정의를 읽는다. 저장소 안내에 정의 형식을 설명한다. 다른 자산의 검색 경로를 보존한다.
- [ ] 새 이름의 선종은 해당 정의로 생성한다. 같은 이름의 선종이 이미 있으면 패턴이 달라도 원래 정의와 참조를 재사용한다.
- [ ] 같은 Recipe를 반복 적용해 선종이 중복 생성되거나 기존 도면 참조가 바뀌지 않는지 검증한다.

**검증 상태**

`91eb05b`에 통합. 저장소 manifest 하나를 런타임에서 읽고 wheel의 정의 파일과 바이트 일치를 확인. Python 39개, C# 모의 설치·재사용·반복 적용과 SDK 참조 컴파일 통과. 실제 Rhino 검수 대기.
