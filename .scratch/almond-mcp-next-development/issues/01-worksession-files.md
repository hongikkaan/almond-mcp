# 01: 프로젝트 등록 파일과 Worksession 첨부 구분

**What to build:** 초기 프로젝트 정보에서 DB에 등록한 Rhino 파일과 현재 문서에 실제 첨부된 Worksession 파일을 각각 확인할 수 있다.

**Blocked by:** None (can start immediately)

**Status:** integrated

- [ ] 등록 파일의 이름과 파일별 설명을 반환하며, 기존 등록 경로·식별자와 설명이 없는 레거시 레코드를 처리한다.
- [ ] 실제 첨부 목록에서 활성 문서를 제외하며 첨부 없음과 조회 실패를 구분한다.
- [ ] Rhino에서 관측한 첨부 파일을 DB에 자동 등록하거나 갱신하지 않는다. 각 작업에는 그때 필요한 파일만 첨부한다. 조회 전후 DB 파일 목록의 동일성을 검사한다.
- [ ] DB에 등록한 파일과 실제로 첨부한 파일이 서로 다른 복제본에서 두 목록을 대조한다.

**검증 상태**

읽기 전용 질의 `e4b70aa6`, 파일명 관계 이관과 명시 등록 `de9e28d9`, 공개 연결 `1cb29c4`에 통합. 통합 stdio·프로젝트 파일·Phase 경계 검사 46개 통과. 충돌 DB의 이관 전후 바이트 동일성을 확인. 실제 Rhino 복제본 관찰은 검수 대기.
