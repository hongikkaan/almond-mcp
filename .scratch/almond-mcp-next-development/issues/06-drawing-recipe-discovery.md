# 06: A4 Recipe 발견·상세·적용

**What to build:** 사용자가 A4 Drawing Recipe를 찾고 올바른 사례를 확인한 뒤 실제 도면 스타일을 적용할 수 있다.

**Blocked by:** None (can start immediately)

**Status:** integrated

- [ ] 목록의 상세 조회 안내와 상세의 스타일 적용 안내를 실행 가능한 흐름으로 유지하거나 보완한다.
- [ ] 현재 A4 Recipe와 실제로 읽히는 유효한 예제, 연결 환경의 검색 경로, 색인 갱신 시점을 확인한다.
- [ ] 복제본에서 발견부터 반복 적용까지 검증한다. 기존 선종 및 PAT 경계로도 독립적으로 검증할 수 있다.

`252d5de`에 통합. 레시피 공개 흐름 4개와 분리 설치 wheel 경로 검증 통과. 실제 Rhino에서 반복 적용 검수 대기.
