# 09: 선택한 Worksession 참조를 PlanSection에 포함

**What to build:** 사용자가 첨부 포함 여부를 선택하면 해당 범위에서 평면·단면이 생성되고 응답에서 실제 추출 조건을 확인할 수 있다.

**Blocked by:** [08 · 활성 모델의 PlanSection 생성·갱신·이동과 결과 반환](08-plansection-current-document.md)

**Status:** integrated

- [ ] 08의 공개 호출·결과 계약에 참조 선택을 연결한다. 활성 문서와 첨부 식별 기준은 01과 공유하되 01의 등록 목록 구현은 필요하지 않다.
- [ ] 활성 객체와 첨부 객체가 겹치는 복제본에서 포함·제외 결과 및 현재 문서·첨부 clipping을 비교한다.
- [ ] 단면·가림·중복 선·선량·성능을 대조하고 그 결과에 근거해 합성 방식을 정한다. 형상 비교와 fixture 준비는 08과 병행할 수 있다.
- [ ] 범위 변경 시에도 생성 응답은 실제 적용 조건을 설명하고, 배치 및 Update에 필요한 식별정보를 보존한다.

**검증 상태**

`58c0bab`에 통합. 첨부 범위·가림·빈 결과 교체의 오프라인 PlanSection 검사 84개와 통합 범위 검사 61개 통과. 실제 Rhino의 가림·선량·성능 검수 대기.
