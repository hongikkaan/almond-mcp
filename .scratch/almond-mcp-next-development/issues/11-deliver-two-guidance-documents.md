# 11: 연결된 에이전트에게 두 기본 문서 전달

**What to build:** 연결된 에이전트가 기본 업무 지침과 설계 판단 원칙 두 문서의 본문을 전달받는다.

**Blocked by:** None (can start immediately)

**Status:** integrated

- [ ] 기존 BASIC-INSTRUCTIONS.md와 같은 위치의 design_judgment.md를 지원 연결 경로에 전달한다. 설계 판단 원문이 없으면 빈 파일을 사용한다.
- [ ] 테스트 본문으로 파일 누락과 미전달, 길이와 잘림, 중복 전달, 버전 갱신의 확인 경로를 검증한다.
- [ ] 최종 본문이 준비되면 실제 전달 내용을 대조한다. 본문 확인을 기다리는 동안 로더를 구현·검증할 수 있으며, 실제 본문 확인 뒤 이 티켓의 검수를 완료한다.

**검증 상태**

`7bd5648`에 통합했다. 기존 BASIC 문서와 0바이트 설계 판단 파일을 세 경로에서 한 번씩 전달했다. wheel·sdist 바이트 대조와 당시 별도 앱 경유 연결의 회귀를 포함해 관련 검사 39개가 통과했다. 당시 Beyond의 실제 MCP 초기화 응답에서 BASIC 본문 전체와 `design_judgment.md`의 빈 문서 상태를 각각 한 번 받았다.
