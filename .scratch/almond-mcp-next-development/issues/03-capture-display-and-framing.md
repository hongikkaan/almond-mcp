# 03: 표시 모드 선택과 객체 중심 캡처

**What to build:** 설계 검토자가 설치된 표시 모드와 특정 객체를 선택해 원하는 장면을 캡처할 수 있다.

**Blocked by:** None (can start immediately)

**Status:** integrated

- [ ] 설치된 기본·사용자 정의 모드를 이름 또는 GUID로 선택할 수 있으며, 호출 전 모드의 용도와 객체 ID 프레이밍 방법을 찾을 수 있다.
- [ ] 복제본의 같은 대상에서 기본·사용자 정의 모드를 각각 호출해 출력 이미지와 실제 적용 모드를 확인한다.
- [ ] 객체 ID로 범위를 좁힌 캡처와 필요한 다방향 뷰를 검증하고, 임시 캡처가 기존 뷰·표시 상태를 바꾸지 않는지 확인한다.

**검증 상태**

`1fd615dc`에 통합. 작업 브랜치 캡처 57개, 병합 담당 집중 검사 16개와 RhinoCommon 참조 컴파일 통과. 실제 기본·사용자 모드, PNG, 카메라·화면 상태 검수 대기.
