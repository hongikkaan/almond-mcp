# 01 · Plan 완료 전환의 정리 안내

사용자가 완료를 확인하고 Plan 상태가 실제로 completed로 바뀌면 기존 응답에서 이 Plan에서만 쓰고 이제 필요 없는 객체·레이어·레이아웃·Named View를 정리하도록 안내한다.

**선행 티켓** 없음

**상태** ready-for-agent

## 수용 기준

- [ ] 최초 완료와 재완료는 각각 한 번 안내한다. 동시에 같은 Plan의 완료를 요청해도 실제 전환을 저장한 호출에서만 안내한다.
- [ ] 마지막 Step·Phase 완료, 반복 완료 요청, 이미 완료된 Plan의 속성 수정, 완료 저장 실패에서는 마무리 문구를 표시하지 않는다.
- [ ] 기존 오류와 부분 성공 정보는 보존하고 안내만 추가한다. 모델 삭제나 PDF 내보내기를 실행하지 않는다.
