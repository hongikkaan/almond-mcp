# 02 · 간섭 미판정의 대상과 공차 표시

간섭 검사와 검토에서 전체 범위의 0건과 계산 미완료를 구별하고, 추가 확인이 필요한 객체나 쌍을 찾을 수 있게 한다.

**선행 티켓** 없음

**상태** ready-for-agent

## 수용 기준

- [ ] 모든 페이지의 검사가 끝나야 총건수를 확정한다. 확인된 0건과 양수는 정상 결과이며, 뒤쪽 페이지 실패는 미판정이다.
- [ ] 미판정에는 실제 확인한 대상·이유·공차와 단위를 표시한다. 실패 대상을 특정할 수 없거나 공차를 받지 못한 경우에는 확인 불가로 표시한다.
- [ ] 기하 알고리즘과 의도적으로 검사에서 제외한 대상의 취급을 보존한다.
