# 03 · 명시적 블록 캡처의 호출 오류

캡처에 지정한 최상위 블록 인스턴스를 지원할 수 없을 때 사용자가 문제 GUID와 입력 위치를 알고 바로 고칠 수 있게 한다.

**선행 티켓** 없음

**상태** ready-for-agent

## 수용 기준

- [ ] 공통 object_ids 또는 타일별 object_ids에 해당 블록이 하나라도 있으면 전체 호출이 오류이며 이미지와 저장 경로를 반환하지 않는다.
- [ ] 일반 객체와 혼합되거나 같은 블록을 여러 타일에서 지정해도 실제 문제 GUID와 입력 위치를 알 수 있다.
- [ ] 명시적 필터 없이 보이는 블록과 블록 이외의 타일 실패에 따른 정상 부분 성공을 보존한다. 별도 객체 조회·새 Bridge 명령 없이 기존 캡처를 사용하고, 수정된 Bridge는 오프라인 빌드·검증한다.
