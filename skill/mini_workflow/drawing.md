# 도면 제작·검토

Layout은 도면을 구성하는 시트이고, Detail View는 그 안에서 모델이나 도면의 특정 범위를 보여주는 창이다. Layout과 Named View는 설계의 일부다. 제목과 메타데이터에 내용과 역할을 압축하고, Layout의 description에는 검토 논점과 이슈를 요약한다. 긴 설명은 도면 안에 둔다. 이전 상태를 현재 설계인 것처럼 남기거나 보고하지 않는다.

1. **열기 또는 구성.** 무엇을 보여주고 판단할지에 맞춰 범위와 축척을 정한다. 기존 Layout·Detail이 요청 범위·축척·현재 도면과 맞으면 그대로 열고 출력한다. 맞는 Detail이 없거나 도면 갱신이 필요하면 필요한 것만 구성한다.
2. **원본 편집 또는 추출.** 직접 설계하는 2D 원본은 해당 원본을 편집하며 이를 위해 3D 모델 생성을 강제하지 않는다. 모델에서 평·단면이 필요하면 PlanSection으로 추출하거나 갱신한다. 직접 작성한 2D 원본, 추출한 도면선, 벽체·가구·블록 등은 `ModelSpace`에 둔다. `PageSpace`에는 Detail View와 제목·축척 등 시트 주석만 두고, 도면 형상은 Detail View로 보여준다. 파생 도면을 갱신하기 전에 보존할 수동 표현을 확인하고, 갱신 후 모델·도면과 필요한 연관 도면을 대조한다.
3. **실제 출력에서 검토.** `capture_04-defined_view` tool로 Layout을 캡처하고, 실제 전달 형식에서 축척·표기·잘림·읽힘을 확인한다. 설계 검토에서는 캡처에서 공간과 사용 관계를 읽고 형상과 치수로 대조한다. 평면만으로 확인하기 어려운 경우 단면·입면·모델이나 지정된 Named View를 함께 살핀다. 확인한 사실, 해석, 가정, 미확인을 구분한다.

   도면에서 공간의 구성과 사용 관계를 읽을 때 [도면 분석 지침 원문](../docs/drawing-analysis.md)을 참고한다.

4. **시트 귀속 검수.** Layout을 구성·변경하거나 귀속을 검수할 때는 출력만 보지 말고 숨겨진 객체와 용지 밖 객체까지 `Space`와 `ViewportId`로 확인한다. 시트에 보이지 않는 잘못된 귀속도 통과로 보고하지 않는다. 모델 공간에 같은 원본이 있는지 먼저 확인한다. 원본의 모델 좌표가 맞으면 이동·재생성하지 말고 귀속만 바로잡아 형상·좌표·ID를 보존한다. 정리 후 모델 공간의 원본과 페이지의 Detail View·시트 주석을 다시 확인한다.
