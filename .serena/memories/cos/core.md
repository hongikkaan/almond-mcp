# 외부 연결기와 AlmondRhino

- `src/cos`는 beyond·CoS 공용 host/worker와 도구 카탈로그를 소유한다. MCP runtime의 확장 훅 위에서 검증·바인딩한다. 계약은 `src/cos/SPEC.md`.
- 클라이언트 시작 시 MCP `tool_declarations.py`의 공용 선언 판독기로 현재 소스에서 카탈로그를 만든다. `data/tool_catalog.json`은 개발용 export다. 실제 worker 계약과 source fingerprint를 대조하고 선택한 연결의 lease·receipt를 보존한다. `external_host.Broker`는 연결 탐색·선택·attach·detach를, `execution_invocation.ExecutionInvocations`는 호출 접수·전송·대기·취소·결과 회수를 맡는다. 실제 완료 판정과 native fence는 공통 runtime에 둔다. 외부 worker의 첫 완료 근거 대기는 min(요청 timeout, 60초)이고 긴 작업은 정확한 RhinoCode 실행 ID로 조회한다. 전용 Terminal의 요청 대기값과 외부 클라이언트 600초 설정은 유지한다. 대기 종료를 강제 취소·rollback·재실행 허가로 해석하지 않는다. 세부 상태·상관 ID·예약 해제 조건은 `src/cos/SPEC.md`와 `src/mcp/runtime/RHINOCODE-SPEC.md`를 따른다.
- AlmondRhino C# 원본은 `src/cos/rhp`, 출력은 `src/rhp/AlmondRhino/plugin-runtime`. 일상 Rhino 등록과 CoS 실행 경로는 `AGENTS.md`의 일상 폴더에 고정한다. 사용자 허가를 받은 통합 검수에서는 `src/rhp/tools/start_integration_rhino.ps1`로 두 워크트리 RHP의 로드를 확인하는 즉시 기존 등록을 복원한다. 시작 스크립트는 같은 워크트리의 Beyond로 Rhino PID·시작 시각·시험 모델을 대조해 `ready` 연결을 확인하고 해제한다. 기능 검수는 반환된 `host_id`로 같은 워크트리에서 연결한다.
