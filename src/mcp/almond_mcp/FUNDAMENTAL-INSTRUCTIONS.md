Almond combines Rhino modelling with a semantic asset library.

The runtime sets ALMOND_PROJECT_ROOT and applies the bound document path automatically. Query project_info only when project information is needed; its default document section already observes the live Rhino document. Select a Plan once with set_working_plan before writing artifacts. Managed output tools reuse its project-relative tmp/YYMMDD_name folder. execute_project_python runs there, while Rhino C# uses ManagedFiles.Input(relativePath) and ManagedFiles.Output(relativePath). Pass relative paths; do not invent per-call folders or database copies. rename_artifact_folder updates current references when a folder name changes. Do not move files or save the Rhino model merely to set an output path.

For reusable objects: prepare and visually review a millimeter, Z-up, bottom-center 3DM, then register_drawing_asset. Registration derives plan/front/right DXF and SVG plus dimensions under the same asset ID. Use get_drawing_asset, get_asset_drawing and place_drawing_asset. generate_asset_drawing_views remains available for a custom static GLB; verify outputs with audit_asset_drawing.

search_detail_sources returns candidate directories, not verified construction details. Choose materials with list_materials and use assign_material; existing layers are preserved. Use setup_modeling to register library materials or create construction-system layers.

Register physical assemblies as Components: an object has at most one Component, each Component belongs to one or more Scenes, and raw objects may also link directly to a Scene. Use get_modeling_policy for keys; object names are free. Organize work as Phase > Plan > Step; Plans reference Scenes and Components, Steps may override Component targets. Work may pause, switch tasks and resume without completing earlier steps. Plan depends_on is an unrestricted array of related Plan/Phase IDs, including other phases; it is not an execution prerequisite. Record file_name on Phase/Scene and artifact references on Plans/Steps. Query IDs only with include_ids=true when needed. get_selection_references maps the current selection to registered Component and Plan/Step references. Inspect geometry relevant to the proposed edit. Asset instances and Room bounds remain optional legacy placement checks; validate_scene_layout covers those cached asset instances, not all Component geometry. Drawing assets use their library manifests; Sheet/ drawing DB registration is retired, while Rhino layouts remain usable.

Use measured dimensions, not nominal prompt targets. Usage suggestions are heuristics and clearances are design allowances, not certified code compliance.
