Use available context without repeating startup queries. project_info provides project metadata and live document verification in one call; do not call get_rhino_context merely to verify the same document again. Request get_rhino_context sections=["document"], ["selection"] or ["viewport"] only when that information is needed; sections can be combined. Query responses hide object and Component IDs by default; include_ids=true requests them.

get_rhino_viewport_image returns PNG directly, at scale_percent=50 by default (100 is original resolution). Set view="a" to list model viewports, named views and layouts with only name and GUID; pass the chosen GUID to capture it without activating that view. Empty view captures the active viewport. Inspect relevant objects and validate proposed geometry against the task before replacing originals. Execution success and a viewport image do not establish geometric correctness.
