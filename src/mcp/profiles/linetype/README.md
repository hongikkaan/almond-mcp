# 도면 레시피의 선종 정의

[매니페스트](manifest.json)는 도면 레시피가 사용하는 선종 이름과 패턴을 정의한다. JSON의 키는 선종 이름이다. 값은 순서대로 적용할 세그먼트 배열이며, 각 세그먼트는 유한한 양수 길이 `length`와 실선 여부 `is_solid`를 갖는다. 공백의 `is_solid`는 `false`이고 한 패턴에는 실선 세그먼트가 하나 이상 필요하다.

스타일 적용 중 새 선종이 필요할 때 실행기는 이 매니페스트에서 해당 이름을 찾는다. 설치 패키지에는 동일한 파일이 `almond_mcp/profiles/linetype/manifest.json`에 포함된다. Rhino 문서에 같은 이름의 선종이 있으면 문서의 정의와 참조를 재사용한다.
