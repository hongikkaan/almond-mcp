# 도면 레시피의 선종 정의

[매니페스트](manifest.json)는 도면 레시피가 사용하는 선종 이름과 패턴을 정의한다. JSON의 키는 선종 이름이다. 값은 순서대로 적용할 세그먼트 배열이며, 각 세그먼트는 유한한 양수 길이 `length`와 실선 여부 `is_solid`를 갖는다. 공백의 `is_solid`는 `false`이고 한 패턴에는 실선 세그먼트가 하나 이상 필요하다.

스타일 적용 중 새 선종이 필요할 때 실행기는 이 매니페스트에서 해당 이름을 찾는다. 설치 패키지에는 동일한 파일이 `almond_mcp/profiles/linetype/manifest.json`에 포함된다. Rhino 문서에 같은 이름의 선종이 있으면 문서의 정의와 참조를 재사용한다.

## 표준 D 작도용

[표준 D 레시피](../drawing/standard_d.json)의 수동 작도 레이어가 사용하는 선종이다. 선종 번호와 기본 패턴은 [ISO 128-2:2022](https://www.iso.org/standard/83355.html) 표 1·4 및 부속서 A의 공칭값을 사용한다. 건설 도면에서의 선종 사용은 부속서 B를 참조한다.

| Rhino 이름 | 용도 | ISO 선종 | 인쇄상 반복 패턴(mm) |
| --- | --- | --- | --- |
| Continuous | 단면 윤곽, 입면 윤곽, 일반선·치수·기호·해치 | 01 실선 | Rhino 내장 |
| ALMOND D ISO 02 Dashed | 숨은 모서리 | 02 파선 | 대시 2.16, 공백 0.54 |
| ALMOND D ISO 04 Long dash dot | 중심선·축선 | 04 일점쇄선 | 대시 4.32, 공백 0.54, 점 0.09, 공백 0.54 |

파선 및 일점쇄선 수치는 표준 D의 인쇄 선폭 0.18 mm를 기준으로 한다. Rhino의 반복 선종 자체가 선의 끝·교점·짧은 선에 대한 ISO 배치 규칙을 검사하지는 않는다.
