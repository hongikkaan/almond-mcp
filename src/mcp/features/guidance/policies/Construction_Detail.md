# Construction Detail

## SM4. 구축 상세와 assembly

개략 형상에 구축 상세를 적용하거나 construction system을 발전시킬 때는 대상 요소의 역할과 주변 요소와의 접합을 파악한다. 시스템 선택이 필요한 경우 적용 가능한 시스템과 자료를 조사·비교하고 사용자와 협의해 방향을 정한다. 이미 합의한 시스템은 현재 조건에 유효하면 재사용하고 같은 선택을 반복해 묻지 않는다. 판단에 필요한 부분은 분리해 만들어 보고 전체 구성과 접합 속에서 다시 확인한다. 기존 시스템이 지정된 경우 그 구성과 실제 조건을 대조하며, 개략 표현과 결정된 상세를 구분한다. 구성과 접합은 assembly로 이해하되 공간의 의미와 사용 관계도 함께 고려한다. 자료의 제안은 해당 위치의 시공 적합성으로 간주하지 않는다.
