# 관찰·검수

현재 Step의 결론에 여러 조회·이미지·계산 결과를 연결하거나, 이전 Step의 근거를 재사용할 때 적용한다. 관찰 시점과 범위를 고르고 실제 이미지를 읽는 기본 원칙은 BASIC을 따른다.

## OB1. 같은 대상을 설명하는 근거끼리 연결한다

관찰 전에 요청에서 확인할 관계와 적용할 판정 기준을 정한다. 기준이 확인되지 않았으면 임의의 통과값을 만들지 않고 미확인으로 남겨 관찰·평가·보고에 연결한다.

근거의 문서·대상 집합·설계안·변경 시점과 표현 상태를 맞춘다. Scene 구성원 목록, 화면에 보이는 객체, 실제 공간의 연결은 서로 다른 범위다. 격리·clipping으로 제외된 부재를 실제로 없는 것으로 읽지 않는다. 단면이나 다른 시점에서 이어지는 관계가 필요하면 그 관계를 드러내는 근거를 보완한다.

수치와 그림이 다르면 먼저 같은 대상과 조건을 비교하는지 확인한다. 비교 범위를 맞춰도 모순이 남으면 어느 결과가 어떤 결론을 지지하는지 구분하고, 결론에 필요한 쪽을 추가 관찰한다. 편리한 결과 하나를 골라 나머지를 무시하지 않는다.

## OB2. 발견하지 못한 것과 확인한 부재를 구분한다

현재 범위의 조회에서 나오지 않은 객체, 일부 검사에서 발견되지 않은 충돌, 해석 불가능한 결과는 각각 그 범위의 결과다. 결과가 비어 있어도 확인하려던 관계 전체를 검사했는지 먼저 판단한다. 충돌 없는 솔리드 쌍이 나왔다는 사실은 통행·접근·조립 가능성의 검증이 아니다.

보고할 주장을 확인된 범위로 제한한다. 요청의 핵심 판단에 미확인이 남으면 필요한 관찰·검증으로 이어가고, 관측 수단이 부족하면 해당 판단을 미확인으로 남겨 다음 결정의 조건에 포함한다. 관측 도구의 페이지·지원 형상·오류·결과 회수 절차는 해당 출력과 안내를 따른다.

## OB3. 근거의 유효기간을 변경 영향으로 판단한다

다음 Step의 작업이 이전 근거의 대상이나 조건을 바꿨으면 해당 근거로 현재 결과를 설명할 수 있는지 다시 판단한다. 모델 수정 전 캡처, 도면 갱신 전 Layout, 다른 설계안의 치수를 최신 결과에 섞지 않는다. 변화와 무관한 기존 근거는 원래 대상·시점을 밝혀 재사용한다.

검수 Step이 끝난 뒤에도 Layout 배치·출력·정리가 전달 내용을 바꾸면 그 영향 범위를 확인한다. 상태값이나 마지막 검수 Step의 존재가 최종 전달물의 정확성을 대신하지 않는다.
