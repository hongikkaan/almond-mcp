# 기본 지침의 참고자료

기본 작업 지침의 원본은 [BASIC-INSTRUCTIONS.md](../../../BASIC-INSTRUCTIONS.md)다. `context_01-get_policy tool()`는 BASIC 전문과 공개 도구명 목록을 반환한다. 개별 도구의 설명 전문과 입력 형식은 `tools/list`에서 직접 제공하며 별도 원문 조회는 없다. 내장 Rhino 스크립팅 자료는 `context_01-get_policy tool(policy="rhino_scripting")`로 요청한다.

이 폴더는 BASIC에서 링크한 참고 Markdown과 원본 이미지를 보관한다. 토픽별 가이드·토픽 맵·이미지 첨부 조회는 제공하지 않는다. 참고자료의 출처·이미지 바이트는 보존한다.

정확한 조회·버전·세션 갱신 계약은 [MCP SPEC](../../../SPEC.md#모델링-안내-전달)을 따른다. `authoring-request.md`는 보존된 작성 요청이며 실행 지침이 아니다.
