# 기본 지침의 참고자료

기본 작업 지침의 원본은 [BASIC-INSTRUCTIONS.md](../../../BASIC-INSTRUCTIONS.md)다. `context_01-get_policy` tool에서 기본 지침과 `available_policies`를 확인한다. 활동별 원본은 [policies](../policies)에 있으며 `policy`로 지침을 선택한다. 내장 Rhino 스크립팅 자료는 `policy="rhino_scripting"`으로 요청한다. 개별 도구의 설명과 입력 형식은 `tools/list`에서 확인한다.

이 폴더는 BASIC에서 링크한 참고 Markdown과 원본 이미지를 보관한다. 자료는 BASIC의 해당 설명에서 연결한다.

정확한 조회·버전·세션 갱신 계약은 [MCP SPEC](../../../SPEC.md#모델링-안내-전달)을 따른다. `authoring-request.md`는 보존된 작성 요청이며 실행 지침이 아니다.
