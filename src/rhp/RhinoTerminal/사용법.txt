Rhino Terminal + Almond

현재 저장소의 통합 RhinoAlmondBridge.rhp와 공용 Engine을 사용합니다.
빌드: 리포 루트에서 ./src/rhp/build.ps1
설치: src/rhp/RhinoAlmondBridge/plugin-runtime/RhinoAlmondBridge.rhp
같은 폴더의 DLL·archive·licenses·JSON 파일을 함께 유지합니다. 별도 RhinoTerminal.rhp는 설치하지 않습니다.

1. 평소처럼 Rhino에서 작업할 .3dm을 엽니다. 새 문서는 먼저 저장하세요.
2. Rhino 명령창에 RhinoTerminal을 입력하고 On을 선택합니다. PowerShell과 Almond 제어 연결이 시작됩니다.
3. 패널이 보이지 않으면 RhinoTerminal → PanelToggle로 표시합니다.
4. 검은 터미널에서 almond를 입력하고 Enter를 누르거나, 패널 오른쪽 위 almond 버튼을 누릅니다.
5. Codex 입력칸이 뜨면 작업을 요청합니다. 현재 Rhino 문서에 연결됩니다.

Rhino를 켜거나 패널이 복원되어도 터미널은 자동 실행되지 않습니다.
RhinoTerminal 명령은 On / Off / PanelToggle 중 하나를 선택합니다.
  On: 패널 표시와 무관하게 실행합니다. 이미 실행 중이면 그대로 유지합니다.
  Off: 패널 표시와 무관하게 터미널과 그 자식 프로그램을 종료합니다. 패널 표시는 유지합니다.
  PanelToggle: 패널을 표시하거나 숨깁니다. 실행 상태는 바꾸지 않습니다.
패널의 「새 터미널」로도 시작할 수 있습니다. 실행 중이면 확인 후 새 셸로 바꿉니다.
오른쪽 위 almond / resume 버튼은 각각 almond / almond resume를 입력하고 Enter를 보냅니다.
셸이 준비되면 버튼이 활성화됩니다. PowerShell 프롬프트에서 사용하세요.

codex가 아니라 almond로 시작하세요. 이미 일반 Codex가 열려 있으면 /exit로 나온 뒤 almond를 입력합니다.
패널 안에서 외부 「Almond 시작.cmd」를 실행하지 마세요. 그것은 별도 Rhino를 여는 실행기입니다.
CLI·Terminal·COS가 A–J의 10개 슬롯을 함께 사용합니다.

이전 대화 이어가기
  1. Codex가 실행 중이면 입력칸에 /exit를 입력해 PowerShell로 나옵니다.
  2. 같은 검은 터미널에 almond resume를 입력하거나 오른쪽 위 resume 버튼을 누르고 이전 대화를 선택합니다.
     ID를 알면: almond resume <대화 UUID>
  현재 Rhino 문서의 연결과 DB/TEMP를 새로 적용하고 이전 대화 기록을 이어갑니다.
  현재 모델에 해당하는 대화를 선택하세요. 대화 선택 자체가 Rhino 파일을 바꾸지는 않습니다.
  Codex 안의 /resume은 기존 MCP와 새 MCP의 잠금이 겹칩니다. /exit 후 almond resume를 사용하세요.
  Codex 종료 화면에 codex resume가 표시돼도, 이 패널에서는 almond resume로 입력하세요.
  목록은 Enter로 선택, Ctrl+C로 취소합니다. 취소하면 연결을 해제하고 PowerShell로 돌아옵니다. Esc는 새 대화입니다.

저장 위치: 모델 폴더의 .almond\scene.sqlite3 및 .almond\tmp\
같은 모델 폴더에서 DB를 공유하며, 각 연결은 자기 token/session/call 디렉터리를 소유합니다.
Codex의 작업 폴더는 UNIT.3dm이 있는 폴더입니다. 공용 Python은 src\engine\.venv를 사용합니다.
이미 실행 중인 Rhino 자체의 임시 폴더와 Codex 로그인·대화 기록 저장소는 바꾸지 않습니다.
AI의 검토 파일·스크린샷·임시 코드는 project_info의 artifact_dir(위 tmp 폴더)를 사용하도록 전달합니다.
다른 절대 경로를 코드에 직접 쓰면 환경변수와 무관하게 그곳에 저장되므로, 모든 파일 쓰기를 강제 제한하는 기능은 아닙니다.
tmp에는 순수 캐시 외에도 PDF·스크린샷·작업 코드·모델 복사본이 들어갈 수 있어 종료 때 자동 삭제하지 않습니다.
남길 자료를 먼저 확인하고, 관련 작업 종료 후 재생성 가능한 캐시/필요 없는 중간 자료만 선별 정리하세요.

Codex만 끝내기: /exit → 일반 터미널로 돌아갑니다. Rhino와 DB는 남습니다.
작업 끝내기: Rhino에서 Ctrl+S → Rhino 닫기. 해당 터미널과 그 자식 프로세스도 종료됩니다.
패널의 X는 숨기기입니다. 작업은 계속됩니다. 다시 RhinoTerminal → PanelToggle로 표시합니다.
패널이 없어도 출력과 문서 연결 확인은 계속되며, 다시 열면 최근 출력을 표시합니다.
Off·「종료」·「새 터미널」은 진행 중인 프로그램을 중단하므로 작업을 마친 뒤 사용하세요.

연결 중 다른 .3dm을 열거나 Save As로 이름을 바꾸지 마세요. 문서가 바뀌면 기존 연결은 무효화됩니다.
파일을 바꾸려면 먼저 Codex에서 /exit → Rhino에서 파일 열기 → 터미널에서 almond.
이름 변경: 관련 연결을 종료한 뒤 UNIT.3dm을 HOUSE.3dm으로 변경합니다. 공용 .almond 폴더 이름은 바꾸지 않습니다.
위치 변경: 같은 폴더를 사용하는 모든 관련 연결을 종료하고, 모델 폴더와 공용 .almond를 함께 옮깁니다.
여러 모델이 공유하는 .almond를 한 모델만의 데이터로 간주해 삭제하거나 옮기지 마세요.
새 위치의 .3dm 열기 → RhinoTerminal On → 필요하면 PanelToggle → almond/almond resume. 기존 DB와 tmp를 이어 씁니다.
과거 코드/기록의 절대 경로, 외부 텍스처/참조 파일과 공용 에셋까지 자동 수정/이동하는 기능은 아닙니다.
같은 모델의 중복 연결은 차단합니다. 기존 외부 Almond 연결도 자동으로 인수하지 않습니다.

오류가 나면 창을 캡처하세요. 설정이나 DB를 임의로 지울 필요는 없습니다.
이전 버전 패널이 이미 열려 있었다면 모델을 저장하고 해당 Rhino를 다시 실행해야 almond resume 인수가 전달됩니다.
