# 사용자 지시 목록 — 2026-10-20~21 세션 검토

이 문서는 스킬 유지보수의 근거 기록이다. 일반 Rhino 작업에서 읽어야 하는 지침을 추가하는 문서가 아니다. S1~S6의 원본 JSONL 경로와 판독 방법은 [세션 검토 기록](2026-10-21-session-audit.md)에 있다. `S2:L632`는 원본 파일의 물리적 행 번호다. 사용자 표현은 요구사항 중심으로 요약했다.

## 적용 원칙

- 최신 지시가 바꾼 요구사항은 이전 지시와 나란히 기록하고 시점을 구분한다. 다른 프로젝트·과업의 수치, 재료, 채널, 작업 순서를 일반 규칙으로 고정하지 않는다.
- 일반적인 역량·품질 요구와 검증 가능한 구체 조건을 구분한다. 모델 복사 여부, 레벨 기준, 검수 뷰, 방 등록 시점 같은 구체 지시를 먼저 충족해야 한다.
- 과거의 질문 요청은 이후의 판단 위임을 무효화하지 않는다. 반대로 판단 위임이 보존 범위나 도구 금지를 해제하지 않는다.

## 스킬에 남긴 공통 요구와 세션 한정 조건

스킬에는 대상 경계, 실제 도구 활용, 계획의 완료 근거, 현재 기준·상세 수준, 의미 있는 설계 검토, 읽기 전용 협업, 등록과 형상의 대응, 결과 최신성과 보고 방식 준수를 남겼다. `-4000/0/4000`, 특정 벽 높이·재료, dark라는 뷰 이름, 특정 건물의 Scene/Room 방식, 특정 Slack 채널은 위 세션의 사실로만 보존했다. 다음 과업은 그 과업의 최신 지시와 실제 모델을 따른다.
